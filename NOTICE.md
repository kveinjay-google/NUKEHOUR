# Current Source Release Notice

The `main` branch is the current audited NUKE HOUR source snapshot corresponding
to iOS/iPadOS version 1.0 (Build 16). Historical Build 4 material remains
available on the `archive/ios-build-4` branch and `ios-build-4` tag.

The project is a modified OpenRA/RA2 codebase. GNU GPL version 3 is preserved in `LICENSE` and `engine/COPYING`; OpenRA and OpenRA RA2 attribution files remain in their source trees. Collected third-party notices are under `third_party/licenses/`. The iOS FreeType archives were built without source modification from official tag `VER-2-13-3` (commit `42608f77f20749dd6ddc9e0536788eaad70ea4b5`) under the FreeType Project License; exact provenance and build flags are in `docs/archive/BUILD4_FREETYPE_PROVENANCE.md`.

Signing certificates, private keys, private profiles, passwords, and API credentials are excluded. Users provide lawful game data at runtime.

Original retail references and unresolved possible derivatives remain outside
this current source projection. The PublicClean application bundle uses a
deny-by-default manifest and contains only approved project-owned or
redistributable presentation resources. Historical Build 4 provenance records
remain under `docs/archive/` for audit continuity.
