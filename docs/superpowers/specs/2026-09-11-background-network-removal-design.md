# NUKE HOUR 后台联网功能移除设计

## 目标

从 NUKE HOUR 的 macOS、iOS 与共享游戏引擎中彻底移除非多人游戏所必需的后台联网能力，使安装后的产品不会访问 OpenRA 公共服务，也不会获取社区新闻、检查版本、收集或发送匿名系统信息。

## 永久保留的联网能力

以下能力属于用户主动发起的正式产品功能，不在本次删除范围内：

- Local Multiplayer：LAN Host、LAN Discovery、Direct IP、TCP 1234。
- Online Multiplayer：NUKE HOUR 在线大厅、房间目录、专用服务器注册与心跳。
- 用户主动点击 NUKE HOUR 官方网站后由系统浏览器打开网页。
- 已建立连接后的游戏协议、地图同步、RuntimeContract、Orders 与本地服务器 MOTD。

不得因为移除 OpenRA 公共服务而削弱 iOS、Android、macOS 作为 Local Host 或客户端的能力。

## 必须移除的能力

### 社区新闻与版本检查

- 删除启动器中的社区新闻、自动获取新闻和自动检查版本设置。
- 删除主菜单新闻下载、缓存与展示逻辑。
- 删除版本检查请求、版本状态与相关提示界面。
- 不再保留可通过命令行或旧配置重新启用这些功能的运行路径。

### 匿名系统信息

- 删除匿名系统信息开关、提示窗口、版本提示状态和 UUID 生成/提交路径。
- 删除只为该提示收集操作系统、运行时、显卡、分辨率或语言信息的代码。
- 删除相关 AOT 注册和界面资源。

### OpenRA 公共服务

- 删除对 `master.openra.net` 的服务器列表、服务器广告、新闻与版本请求。
- 删除对 `resource.openra.net` 的远程地图查询与安装入口。联机只使用本地已有或由产品导入的兼容地图。
- 删除对 `forum.openra.net` 的玩家资料、徽章和认证请求。
- 删除旧的 Itch 自动账户查询请求。
- 删除创建服务器界面中只服务于 OpenRA 主服务器广告的选项，同时保留 LAN 广播。

## 架构边界

共享 `WebServices` 配置只保留 NUKE HOUR 当前实际使用的在线大厅地址。OpenRA 公共端点不得作为默认值、回退值或可选值残留在发布运行时。

`MasterServerPinger` 中的 LAN Beacon 与 Nearby 广播继续工作；只删除面向 OpenRA 主服务器的 HTTP 广告分支。NUKE HOUR 专用服务器的在线大厅注册器属于独立实现，保持不变。

需要认证但没有配置 NUKE HOUR 自有认证服务的服务器必须明确拒绝启动或拒绝认证，不能回退到 OpenRA 玩家资料服务，也不能静默放行。

旧设置文件中已经存在的退役键可以继续被通用 YAML 读取器忽略，但产品不得展示、写入、传递或执行这些键。启动器保存设置时应移除它负责管理的退役键，避免用户误以为这些功能仍然存在。

## 界面与文案

- 删除 macOS 启动器“在线服务”卡片以及社区新闻、版本检查和匿名信息选项。
- 删除游戏内高级设置中对应选项。
- 删除本地化字典中只服务于上述控件的文案。
- 不删除“在线多人游戏”“官方网站”等仍然有效的用户主动入口。

## 测试门禁

- 新增源码与配置审计，发布运行时不得包含 `master.openra.net`、`resource.openra.net`、`forum.openra.net` 或旧 Itch API 端点。
- 新增启动器契约测试，确认退役选项、变量与命令行参数均不存在。
- 新增引擎测试，确认新闻、版本状态、系统信息提示、OpenRA 主服务器广告和远程地图查询路径不存在。
- 验证 LAN Beacon/Nearby、Direct IP、NUKE HOUR 在线大厅配置和专用服务器注册仍然存在。
- 运行 macOS 干净发布包审计、启动器测试、服务器交付测试和相关引擎测试。
- 完成 macOS 发布构建，并对应用包进行禁止域名扫描。

## 非目标

- 不删除或替换 NUKE HOUR Online Multiplayer。
- 不修改多人游戏协议、RuntimeProfile、RuntimeContract 或默认 TCP 1234。
- 不删除本地 GeoIP 数据、MetricKit 本地诊断文件、Discord 本地 IPC 或构建阶段下载引擎依赖的开发脚本。
- 不修改 Android 独立目录；共享代码的变更由 Android 项目后续同步。
