# iOS 设置界面动态缩放设计

## 目标

设置窗口必须完整包含在当前游戏逻辑视口内，并在 iPad 与 iPhone 横屏、不同 UI 缩放倍率下保持相同的布局比例和正确的触控命中位置。

## 根因

现有 iOS 布局只截断外框宽高，内部仍使用固定的 1180×720 指标和 1.45 倍纵向放大。因此视口变小时，外框虽然没有越界，侧栏、按钮和内容树仍会溢出。

## 设计

- 使用 1180×720 作为设计画布，并在四周保留 16 逻辑像素安全边距。
- 打开设置页时，以当前 `Game.Renderer.Resolution` 计算 `min(可用宽度/1180, 可用高度/720, 1)`。
- 外框、标题、侧栏、标签、底部操作按钮和内容区域全部使用同一缩放系数。
- 面板内容在设计画布上仍采用适合触控的 1.45 倍纵向间距，再乘视口缩放；横向按实际内容区域与原始内容区域的比值缩放。
- 滚动面板始终填满内容区域，超出内容通过原有滚动机制访问，不裁掉设置项。
- 桌面端保持原布局不变。

## 验收

- 1180×820、1024×768、844×390 和 590×410 逻辑视口下，窗口边界均位于安全区域内。
- 五个侧栏标签与重置按钮不重叠，返回按钮不越界。
- 内容控件的显示坐标与触控命中坐标一致。
- 原有设置布局测试和 iOS Release 构建通过。
