# 遭遇战选单精简设计

## 目标

仅在本地人机遭遇战中移除让分和就绪控件，释放出的横向空间用于更清晰的玩家设置。

## 布局

玩家行按内容宽度排列为：玩家名、颜色、阵营、队伍、出生点。玩家名使用剩余弹性宽度；颜色与阵营使用中等宽度；队伍和出生点使用紧凑固定宽度。网络大厅保持原有控件与行为。

## 颜色

遭遇战颜色选择只显示游戏既有的经典预设色，不显示自由混色、连续调节或自定义颜色存储入口。有效颜色仍经过现有冲突和地图可见性校验。

## 验证

新增回归测试：遭遇战布局不分配让分或就绪控件；颜色选择不暴露自定义调色控件；网络大厅不受影响。构建签名 iOS 应用并在 iPad 上验证。
